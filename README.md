# Grid Breaker

A small Pygame drag-and-drop puzzle where you place pieces on an 8x8 grid to clear full rows and columns and score combos.

How to run:
1. python -m venv venv
2. source venv/bin/activate  # veya venv\Scripts\activate (Windows)
3. pip install -r requirements.txt
4. python grid_breaker.py

Controls: Drag pieces, Press R to restart, ESC to quit.
